# 채널 가이드 · 채널별 톤·규격·해시태그 전략

> **용도**: 실습에서 채널별 콘텐츠를 만들 때 `content-studio` 스킬이 읽는 채널 정의 파일.
> **핵심 개념**: 같은 메시지라도 **채널마다 원하는 것이 다르다.** 채널이 원하는 것을 모르면 4개 채널에 같은 글이 4번 올라간다. 그건 4개 콘텐츠가 아니라 1개 콘텐츠의 복사본 4개다.
> **⚠ 이 파일에 없는 채널은 생성되지 않는다.** 스킬은 이 표에 적힌 채널만 만든다.

---

## 채널이 서로 다른 것을 원한다

| 채널 | 이용자가 이 채널에 오는 이유 | 그래서 첫 줄에 와야 하는 것 | 실패하는 방식 |
|---|---|---|---|
| **인스타그램** | 넘기다가 **눈에 걸려서** 멈춘다 | 이미지가 먼저. 카피는 이미지를 설명하지 말고 **멈춘 이유를 확인시킨다** | 긴 설명. 이미지 없이 글만 |
| **페이스북** | 아는 사람의 **맥락 있는 이야기**를 본다 | "왜 이게 지금 중요한가"라는 배경 한 줄 | 광고 문구. 해시태그 도배 |
| **네이버 블로그** | **검색해서 들어온다.** 답을 찾으러 온 것이다 | 검색어를 그대로 포함한 제목과 첫 문단 | 감성 에세이. 소제목 없는 긴 글 |
| **유튜브 설명문** | 영상을 보러 왔고, 설명문은 **검색과 보강**을 위해 읽는다 | 영상 내용 3줄 요약 + 검색어 | 영상에 다 나온 내용의 반복 |

**여기서 자동화의 핵심이 나온다.** 변하지 않는 것(사실·수치·기능성 문구·필수 고지)은 복사하고, 변하는 것(첫 줄·길이·격식·해시태그·CTA)만 다시 쓴다.

## ① 인스타그램

| 항목 | 규격 |
|---|---|
| **원하는 것** | 비주얼 우선. 스크롤을 멈추게 하는 한 장면 |
| **첫 줄 (후킹)** | 25자 이내. **"더 보기"가 접히기 전에 승부가 난다** |
| **본문** | 150자 이내. 짧은 문장 3~4개. 줄바꿈으로 호흡을 준다 |
| **이미지** | 1:1 또는 4:5. **콘텐츠의 주인공은 이미지다.** 카피는 조연 |
| **해시태그** | 8~12개. 대형(10만+) 2개 + 중형(1만~10만) 4개 + 소형·브랜드 태그 4개 |
| **CTA** | "프로필 링크" 한 가지만. 인스타는 본문 링크가 눌리지 않는다 |
| **느낌표** | 최대 1회 |
| **금기** | 긴 문단. 표. 링크 나열. 전문 용어 |

**해시태그 전략 (온담 캠페인 기준 예시)**

```
대형 (도달)   #건강기능식품  #눈건강
중형 (관련성) #루테인  #액상루테인  #부모님선물  #눈영양제
소형 (전환)   #루테인지아잔틴  #액상스틱  #온담이너샷  #한포의습관
```

> 대형 태그만 쓰면 묻히고, 소형 태그만 쓰면 아무도 안 본다. **세 층을 섞는 것이 전략이다.**

**첫 줄 예시**

> "부모님이 알약을 뱉으신 날, 바꿨습니다." (23자)

## ② 페이스북

| 항목 | 규격 |
|---|---|
| **원하는 것** | 맥락. "왜 지금 이 이야기인가"를 설명할 지면이 있다 |
| **첫 줄** | 배경이나 문제 제기. 인스타처럼 짧게 끊지 않아도 된다 |
| **본문** | 300자 내외. 3단 구성 (문제 → 근거 → 해법) |
| **이미지** | 1.91:1 (링크 카드) 또는 1:1 |
| **해시태그** | 2~3개. 페이스북에서 해시태그는 도달에 거의 기여하지 않는다. **많이 붙이면 광고처럼 보인다** |
| **CTA** | 본문 내 링크 클릭 유도. 페이스북은 링크가 눌린다 |
| **금기** | 인스타 카피의 복사. 해시태그 10개 |

**본문 구조**

```
[1단] 문제 제기   "정제나 캡슐을 삼키기 어려워 중간에 그만둔 경험, 40대 이상 37.6%"
[2단] 근거        조사 출처 + 제품이 응답하는 지점
[3단] 해법·CTA    "1포 20ml, 물 없이. 자세히 보기 →"
```

## ③ 네이버 블로그

| 항목 | 규격 |
|---|---|
| **원하는 것** | **검색 유입.** 감성이 아니라 답을 준다 |
| **제목** | 검색어를 **제목 앞쪽에** 넣는다. 30자 내외 |
| **본문 길이** | 800~1,200자. 너무 짧으면 검색에서 밀린다 |
| **구조** | **소제목 3개 필수.** 소제목마다 이미지 1장 삽입 지점 표시 |
| **키워드 밀도** | 핵심 키워드를 제목·첫 문단·소제목·마지막 문단에 자연스럽게 반복 |
| **이미지** | 3장 이상. 각 소제목 아래 배치. **대체 텍스트(alt)에도 키워드를 넣는다** |
| **해시태그** | 5~10개. 네이버 블로그는 태그가 검색에 기여한다 |
| **금기** | 키워드 억지 반복 (저품질 문서 판정). 소제목 없는 긴 글 |

**타겟 검색어 (온담 캠페인 기준 예시)**

| 검색어 | 성격 | 배치 위치 |
|---|---|---|
| 액상 루테인 | **주 키워드** | 제목 앞쪽 · 첫 문단 · 소제목 1 |
| 루테인 지아잔틴 차이 | 정보 탐색형 | 소제목 2 |
| 부모님 눈 영양제 | 구매 의도형 | 소제목 3 · 마지막 문단 |

**소제목 3개 구조**

```
소제목 1  "알약이 부담스러운 분들이 액상을 찾는 이유"     ← 문제
소제목 2  "루테인 20mg, 지아잔틴 4mg이라는 숫자의 의미"   ← 근거
소제목 3  "부모님 눈 영양제, 이렇게 고르세요"             ← 행동
```

## ④ 유튜브 설명문

| 항목 | 규격 |
|---|---|
| **원하는 것** | **검색 최적화.** 유튜브는 세계 2위 검색 엔진이다 |
| **첫 3줄** | "더보기"를 누르기 전에 보이는 유일한 부분. **여기에 핵심 키워드와 요약을 넣는다** |
| **본문** | 영상 내용 3줄 요약 → 타임스탬프 → 제품 정보 → 링크 → 고지 문구 |
| **타임스탬프** | `00:00 형식`. 챕터로 자동 인식되어 검색 노출에 기여한다 |
| **해시태그** | 3개까지만. **제목 위에 노출되는 것은 앞의 3개뿐이다** |
| **금기** | 영상에 이미 나온 내용의 반복. 링크만 나열 |

**설명문 구조**

```
[첫 3줄]     핵심 키워드 포함 요약. 이 3줄이 검색에 걸린다
[타임스탬프] 00:00 인사 / 00:35 제형 비교 / 01:20 함량 확인 / 02:10 섭취 방법
[제품 정보]  제품명 · 용량 · 가격 · 기능성 문구
[링크]       공식몰 · 브랜드 채널
[고지]       "본 제품은 질병의 예방 및 치료를 위한 의약품이 아닙니다."
[해시태그]   #액상루테인 #루테인지아잔틴 #눈건강
```

## 모든 채널에서 동일해야 하는 것 (🔒 원본 복사 · 재생성 금지)

```
🔒 채널이 달라져도 절대 바뀌지 않는 것
   · 제품명, 가격, 용량, 함량
   · 식약처 인정 기능성 문구 "눈의 건강에 도움을 줄 수 있음"
   · 필수 고지 "본 제품은 질병의 예방 및 치료를 위한 의약품이 아닙니다."
   · 출시일, 판매 채널
   · 근거 수치와 그 출처 (37.6% · 41.2%)

✍️ 채널마다 달라지는 것 (AI가 다시 쓰는 부분)
   · 첫 줄 (후킹 방식)
   · 문장 길이와 격식
   · 강조하는 근거의 순서
   · 해시태그 · CTA
   · 이미지의 구도와 톤
```

> ⚠ **가격이 채널마다 다르면 그 자체로 사고다.** 인스타에 59,000원, 블로그에 55,000원이 올라가는 순간 소비자 민원과 표시광고 이슈가 동시에 터진다. 확정 사실은 반드시 원본에서 복사한다.

## 공공 클라이언트 채널 규칙 (⚠ 민간과 다르다)

정부·지자체·공공기관 캠페인은 **같은 채널이라도 어투와 표현 규칙이 다르다.** 모드 [C] 선택 시 아래를 적용한다.

| 항목 | 민간 | 공공 |
|---|---|---|
| 주어 | 브랜드명 | **기관 정식 명칭** (약칭은 첫 등장 시 병기) |
| 대상 지칭 | 고객, 소비자 | **국민, 소상공인, 참여자** 등 정책 대상 용어 |
| 형용사 | 제한적 허용 | **사실상 금지.** "획기적인", "최고의", "국내 유일" 배제 |
| 효과 표현 | 단정 가능 | **정책 효과 단정 금지.** "기대된다", "전망이다"로 완화 |
| 수치 | 자사 데이터 | **출처와 기준시점 필수 병기** (예: "2026년 3월 기준") |
| 이모지 | 자유 | **최소화.** 기관 채널 운영지침에 따라 금지인 곳도 많다 |
| 느낌표 | 채널당 1회 | **사용하지 않는다** |
| 해시태그 | 트렌드 태그 활용 | **정책명·사업명 중심.** 유행어 태그는 쓰지 않는다 |
| CTA | "구매하기", "지금 만나보세요" | **"신청 방법 안내"**, "누리집에서 확인하세요" |
| 마무리 | 프로모션 안내 | **신청 방법 · 문의처 · 누리집 주소** |

**같은 문장이 어떻게 바뀌는가**

| 민간 버전 | 공공 버전 |
|---|---|
| "지금 바로 만나보세요!" | "신청은 기관 누리집에서 하실 수 있습니다." |
| "국내 최초의 획기적인 지원사업" | "국내에서 처음으로 시행되는 지원사업" |
| "매출이 확 오릅니다" | "참여 업체의 온라인 매출 비중이 평균 12.4%p 증가했습니다 (2026년 3월 기준, 참여 업체 1,240곳)" |
| "소비자 여러분" | "소상공인 여러분" |

> **공공 SNS는 홍보물이 아니라 공고문에 가깝다.** 화려하게 쓰면 잘 쓴 게 아니라 사고다. 감사에서 지적되는 것은 "재미없다"가 아니라 "정책 효과를 단정했다"이다.

## 이 파일을 내 채널 가이드로 바꾸는 법 (실습 2용)

```
1. 내가 실제로 운영하는 채널만 남긴다.
   유튜브를 안 하면 유튜브 블록을 통째로 지운다.
   ⚠ 지운 채널은 아예 생성되지 않는다. 그게 정상이다.

2. 채널을 추가해도 된다.
   틱톡 · X · 링크드인 · 카카오 채널 · 스레드.
   추가할 때 반드시 4줄을 채운다:
     · 이용자가 이 채널에 오는 이유는?
     · 첫 줄에 뭐가 와야 하나?
     · 이 채널이 싫어하는 것은?
     · 해시태그·CTA 규칙은?

3. 해시태그는 실제 검색량을 보고 3층으로 나눈다.
   대형만 쓰면 묻히고, 소형만 쓰면 아무도 안 본다.

4. 콘텐츠가 잘 될 때마다 갱신한다.
   반응이 좋았던 첫 줄을 이 파일에 적어두면, 다음부터 그 패턴이 재현된다.
```
