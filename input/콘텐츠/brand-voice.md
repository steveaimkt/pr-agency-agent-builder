# 브랜드 보이스 · 온담(ONDAM)

> **용도**: 실습의 톤·규제 기준. `content-studio` 스킬이 이 파일을 읽어 채널별 콘텐츠의 문체를 맞추고 금기어를 검출·치환한다.
> **가상 데이터**: 온담은 교육용 가상 브랜드다.
> **핵심**: 3장의 금기어 표가 이 파일의 심장이다. **표에 없는 표현은 검출되지 않는다.**

---

## 1. 톤 (형용사 3개)

- **담백한**: 감탄사를 남발하지 않는다. 사실을 사실대로 놓는다. "놀라운 효과!"가 아니라 "1포 20ml, 물 없이"
- **근거를 대는**: 숫자를 말할 때는 반드시 출처와 기준시점을 붙인다. 출처 없는 숫자는 아예 쓰지 않는다
- **과하지 않은**: 건강기능식품은 약이 아니다. 기대치를 부풀리지 않는다. 소비자가 실망할 여지를 만들지 않는 것이 장기적으로 브랜드를 지킨다

---

## 2. 핵심 어휘 20개

이 단어들을 우선 투입한다. 온담이 실제로 쓰는 말이다.

```
꾸준히, 챙기다, 도움, 편의, 한 포, 물 없이, 함량, 원료, 공정, 유지,
설계, 검증, 표기, 일상, 습관, 부담 없는, 데일리, 기준, 확인, 선택
```

**쓰지 않는 단어 (금기어는 아니지만 온담답지 않은 말)**
`혁신적인`, `완벽한`, `최강`, `강력한`, `놀라운`, `압도적`, `단 하나의`

## 3. 금기어 표 (🚨 3열 필수. 하나라도 비면 검출되지 않는다)

### 3-1. 건강기능식품법 · 식약처 표시광고 (최우선)

| 금기 표현 | 위반 법령 | 대체 표현 |
|---|---|---|
| 치료, 치료 효과 | 건강기능식품법 제18조 (질병 치료·예방 표방 금지) | (사용 불가. 문장 자체를 삭제) |
| 예방, 예방한다 | 건강기능식품법 제18조 | (사용 불가) |
| 완치, 낫게 하는 | 건강기능식품법 제18조 | (사용 불가) |
| 눈 건강을 지켜주는 | 인정 기능성 문구 이탈 | **눈의 건강에 도움을 줄 수 있음** |
| 눈 건강을 개선하는 | 인정 기능성 문구 이탈 | **눈의 건강에 도움을 줄 수 있음** |
| 시력 회복, 시력 개선 | 건강기능식품법 제18조 · 의료 표현 | (사용 불가) |
| 노안 예방, 황반변성 예방 | 질병명 직접 언급 금지 | (사용 불가. 질병명 자체를 쓰지 않는다) |
| 안구건조증 완화 | 질병명 직접 언급 금지 | (사용 불가) |
| 면역력 강화 | 인정받지 않은 기능성 표방 | (사용 불가) |
| 부작용 없는, 안전한 | 안전성 단정 금지 | 원료 함량을 표기했습니다 |
| 의사가 추천하는 | 의료인 추천 표방 금지 (건강기능식품법 제18조) | (사용 불가) |
| 100% 효과, 확실한 효과 | 효과 단정·과장 | (사용 불가) |
| 최고, 최상, 국내 1위 | 표시광고법 (객관적 근거 없는 최상급) | (근거 자료가 있을 때만. 없으면 사용 불가) |
| 즉시, 하루 만에, 바로 | 효과 발현 시점 단정 | 꾸준히 섭취하면 |
| 완판, 품절 대란, 없어서 못 파는 | 근거 없는 인기 표방 (표시광고법) | (실제 판매 데이터가 있을 때만 사용) |

### 3-2. 표현 과장 (법 위반은 아니나 온담 기준 금지)

| 금기 표현 | 위반 기준 | 대체 표현 |
|---|---|---|
| 기적의, 마법의 | 브랜드 톤 (과하지 않은) | (사용 불가) |
| 혁신적인, 획기적인 | 브랜드 톤 (담백한) | 새롭게 설계한 |
| 압도적인, 강력한 | 브랜드 톤 (담백한) | (수치로 대체) |
| 놀라운, 믿기 힘든 | 브랜드 톤 (담백한) | (사용 불가) |

### 3-3. 비교·비방

| 금기 표현 | 위반 기준 | 대체 표현 |
|---|---|---|
| 타사 제품 실명 비교 | 표시광고법 (비방 광고) | (사용 불가) |
| 기존 제품과 달리 (특정 경쟁사 지칭) | 표시광고법 | 국내 루테인 제품 대부분이 정제·캡슐 형태인 반면 (일반적 시장 서술로) |

## 4. 문장 규칙

| 항목 | 규칙 |
|---|---|
| 문장 길이 | 한 문장 60자 이내 권장. 인스타 첫 줄은 25자 이내 |
| 느낌표 | **채널당 최대 1회.** 공공 캠페인에서는 사용하지 않는다 |
| 존댓말 | SNS는 존댓말("출시했습니다"). 보도자료 선택 모듈은 평서체("출시했다") |
| 숫자 표기 | 아라비아 숫자. 단위 병기 (20mg, 59,000원, 30포) |
| 출처 표기 | 모든 통계·조사 수치에 **출처 + 기준시점 + 표본** 병기. 예외 없음 |
| 기능성 문구 | **"눈의 건강에 도움을 줄 수 있음"** 이 문구 외 어떤 변형도 금지. 축약·의역 금지 |
| 필수 고지 | 모든 채널 하단에 **"본 제품은 질병의 예방 및 치료를 위한 의약품이 아닙니다."** 삽입 |

## 5. 이미지 톤과 저작권 규칙 (🚨 생성 이미지에 그대로 적용된다)

이미지에도 브랜드 보이스가 있다. 그리고 **이미지에는 카피에 없는 위험이 하나 더 있다. 저작권이다.**

### 5-1. 온담의 이미지 톤

| 항목 | 규칙 |
|---|---|
| 색감 | 따뜻한 자연광. 채도 낮음. 과한 보정 금지 |
| 구도 | 제품 단독보다 **일상 속 장면** (식탁, 아침 햇살, 손) |
| 인물 | 40~60대. 과장된 표정 금지. "건강해 보이는 연출"보다 자연스러운 순간 |
| 금지 톤 | 의료·병원 연상 이미지 (흰 가운, 청진기, 임상 장면). **약처럼 보이면 그 자체로 규제 위험이다** |
| 텍스트 삽입 | 이미지 안에 효능 문구를 넣지 않는다. 넣는 순간 그 이미지가 표시광고 심의 대상이 된다 |

### 5-2. 생성 이미지 금지 지시어 (🚨 이 목록에 걸리면 생성 전에 차단된다)

| 금지 유형 | 예시 지시어 | 왜 금지인가 |
|---|---|---|
| **실존 브랜드 로고·제품** | "A사 제품과 나란히", "OO 브랜드 패키지 느낌" | 상표권 침해. 비교광고 규제도 함께 걸린다 |
| **실존 인물 얼굴** | "김혜수 같은 분위기의 배우", "유명 아나운서 느낌" | 초상권·퍼블리시티권 침해. "느낌", "분위기" 같은 완곡한 표현도 유사성 판단 대상이다 |
| **특정 작가·스튜디오 화풍** | "지브리 감성으로", "특정 작가 스타일로" | 저작권·부정경쟁 이슈. 스타일 모방 지시는 분쟁 소지가 크다 |
| **의료 연출** | "의사가 처방하는 장면", "병원 진료실 배경" | 건강기능식품법상 의료인 추천 표방 금지에 걸린다 |
| **효능 시각화** | "흐릿하던 시야가 선명해지는 전후 비교" | 치료 효과 암시. **이미지도 표시광고 대상이다** |
| **레퍼런스 이미지 복제** | 특정 광고 이미지를 붙이고 "이렇게 만들어줘" | 참고와 복제의 경계가 모호해진다. 구도를 말로 설명하는 것은 되지만, 이미지를 그대로 넣는 것은 위험하다 |

**대체 방향 (같은 요구를 안전하게 푸는 법)**

| 원래 요청 | 안전한 대체 프롬프트 |
|---|---|
| "김혜수 같은 분위기의 중년 여성" | "50대 한국인 여성, 특정 인물을 닮지 않은 일반적 외모, 자연광, 편안한 표정" |
| "지브리 감성으로" | "부드러운 파스텔 색조, 손그림 질감의 일러스트, 따뜻한 자연광" |
| "A사 제품과 나란히 비교" | "정제 알약 한 무더기와 액상 스틱 한 포를 나란히 놓은 구도, 브랜드 표기 없음" |

> **핵심 원칙**: 화풍이나 인물을 **이름으로 지시하지 않는다.** 원하는 것을 **시각 속성으로 분해해서** 쓴다. "지브리처럼"이 아니라 "부드러운 파스텔 색조, 손그림 질감, 따뜻한 자연광". 결과물은 비슷하고 위험은 사라진다.

### 5-3. 클라이언트 납품 규칙

| 항목 | 규칙 |
|---|---|
| 사전 합의 | 생성 이미지를 클라이언트 납품물에 쓸 때는 **반드시 사전에 합의**한다. 사후 통보는 사고다 |
| 도구별 약관 | 상업적 이용 가능 범위는 **도구마다 다르다.** 유료 플랜에서만 상업 이용을 허용하는 도구가 있다. 쓰기 전에 약관을 확인한다 |
| 표기 의무 | 클라이언트가 AI 생성물 표기를 요구하는 경우가 늘고 있다. 계약서에 표기 의무 조항이 있는지 먼저 확인한다 |
| 인물 이미지 | 실존 인물처럼 보이는 생성 인물은 **광고 모델 계약과 충돌**할 수 있다. 인물 이미지는 특히 보수적으로 다룬다 |

## 6. 업종 프리셋 (실습 2에서 내 클라이언트 업종 행으로 갈아끼운다)

금기어 표는 클라이언트 업종마다 **완전히 다른 법령**을 참조한다. 내 업종 행을 골라 위 3장의 표를 통째로 바꾼다.

| 업종 | 근거 법령 | 대표 금기 표현 | 대체 방향 |
|---|---|---|---|
| **건강기능식품** | 건강기능식품법, 식약처 표시광고 심의 | 치료, 예방, 완치, 면역력 강화, 부작용 없는 | 인정받은 기능성 문구를 **글자 그대로**. 축약·의역 금지 |
| **화장품** | 화장품법 표시광고 | 미백, 주름 개선, 재생, 항염, 아토피 | 기능성 인증이 있을 때만 고시 문구. 없으면 "환한 인상", "매끈한 결" |
| **의료·병원** | 의료법 제56조 | 최고, 유일, 부작용 없는, 치료 효과 보장 | 시술 사례·의료진 소개로 대체. 환자 유인 표현 금지 |
| **금융·보험** | 자본시장법, 보험업법 광고규제 | 원금 보장, 확정 수익, 최고 수익률, 100% 보장 | 의무 고지 병기 ("과거 성과는 미래 수익을 보장하지 않습니다") |
| **공공기관** | 홍보성 수식 배제 원칙 | 획기적인, 최고의, 국내 유일, 정책 효과 단정 | 사실 서술로. "국내에서 처음으로 시행되는", "기대된다" |

**업종별 이미지 금지 지시어도 함께 바뀐다**

| 업종 | 이미지에서 특히 조심할 것 |
|---|---|
| 건강기능식품 | 의료 연출 (흰 가운·처방 장면), 효능 전후 비교 |
| 화장품 | **전후 비교 사진** (기능성 인증 없이 쓰면 화장품법 위반), 피부 질환 연상 이미지 |
| 의료·병원 | 시술 전후 사진 (의료법상 엄격 규제), 환자 얼굴 |
| 금융·보험 | 수익 그래프 연출 (원금 보장 오인), 고수익 라이프스타일 이미지 |
| 공공기관 | 특정 정당·정치인 연상 이미지, 실존 인물 유사 얼굴 |

> ⚠ **화장품 담당인데 표에 "치료"만 있으면, 이 스킬은 내 클라이언트의 사고를 하나도 못 잡는다.** 표에 없는 표현은 그대로 통과한다.

## 7. 이 파일을 내 클라이언트용으로 바꾸는 법 (실습 2용)

4줄이면 시작된다. 완벽할 필요 없다.

```
1. 톤 형용사 3개를 적는다.   (그 클라이언트의 기존 콘텐츠를 3건 읽고 공통점을 뽑는다)
2. 금기어 3개를 적는다.       (디렉터에게 "우리 클라이언트에서 절대 못 쓰는 말"을 물어본다)
3. 반드시 3열로 적는다.       표현 | 위반 법령 | 대체 표현
                              3열이 채워지지 않으면 스킬이 검출하지 못한다.
4. 이미지 금지 지시어 1줄.    그 브랜드가 이미지에서 절대 피해야 할 것
                              (예: 화장품이면 "전후 비교 사진")
```

리걸 리뷰에서 한 번 지적받은 표현은 **그날 바로 이 표에 추가한다.** 같은 실수가 두 번 나지 않는 것이 이 파일의 목적이다.
