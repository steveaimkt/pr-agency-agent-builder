# 이슈 대응 프로토콜 (위험도 4단계)

> 실습 1에서 이 문서를 그대로 쓴다. 실습 2에서 본인 팀 실정에 맞게 고친다.
> 등급을 매기는 것이 목적이 아니다. **등급마다 누가 무엇을 하는지가 미리 정해져 있는 것**이 목적이다.
> 위기 상황에서 사람은 판단력이 떨어진다. 그래서 판단을 미리 해둔다.

## 0. 이 프로토콜의 대전제

**AI는 감지하고 정리한다. 판단은 사람이 한다.**

이 문장을 프로토콜의 모든 줄 위에 놓는다. 스킬은 신호를 잡고, 묶고, 점수를 매기고, 초안을 쓴다. 그러나 다음 네 가지는 절대 하지 않는다.

| 하지 않는 것 | 이유 |
|---|---|
| 대응 여부 결정 | 대응하지 않는 것이 최선인 경우가 많다. 반응하면 이슈가 커진다 |
| 발표 시점 결정 | 같은 문안도 언제 나가느냐로 결과가 갈린다 |
| 최종 문안 확정 | 한 단어가 법적 책임을 만든다 |
| 외부 발송 | 기자, 클라이언트, SNS 어디에도 스킬이 직접 보내지 않는다 |

### 잘못 나간 해명이 위기를 키우는 원리

사실관계가 확정되기 전에 "문제없다"고 발표하면, 나중에 문제가 확인됐을 때 이슈가 **하나에서 둘로 늘어난다.**

```
원래 이슈  :  제품에 문제가 있었다
추가 이슈  :  회사가 문제없다고 거짓말했다
```

두 번째가 항상 더 크다. 제품 결함은 고치면 되지만 신뢰 붕괴는 고칠 수 없기 때문이다. 언론도 두 번째를 더 좋아한다. 첫 번째는 제품 기사지만 두 번째는 사회 기사다.

그래서 이 프로토콜의 모든 초안 문서에는 워터마크가 박힌다.

```
🚫 배포 금지 · 내부 검토용 초안
   승인권자: ______  승인일시: ______  최종 문안 확정: ______
   위 세 칸이 채워지기 전까지 이 문서는 외부로 나가지 않는다.
```

## 1. 위험도 4축 스코어

각 축 0~3점. 합계 0~12점. 기계가 계산하고 사람이 검증한다.

### 축 1. 부정 보도량 (0~3)

| 점수 | 조건 |
|---|---|
| 0 | 동일 이슈 부정 보도 0건 |
| 1 | 부정 1~2건. 서로 다른 주제로 산발 |
| 2 | **동일 이슈 클러스터에 부정 3~4건** |
| 3 | 클러스터 부정 5건 이상, 또는 전일 대비 3배 이상 증가 |

산발과 클러스터를 구분하는 것이 핵심이다. 부정 5건이 다섯 개 주제로 흩어져 있으면 그것은 평범한 하루다. 부정 3건이 한 주제로 뭉치면 그것은 이슈다.

### 축 2. 매체 등급 (0~3)

클러스터 안의 **부정 보도** 중 가장 높은 매체 등급을 본다.

| 점수 | 조건 |
|---|---|
| 0 | 부정 보도 없음 |
| 1 | T3(전문지·지역지) 또는 T4(커뮤니티·SNS)만 |
| 2 | **T2(주요 경제지·주요 온라인) 진입** |
| 3 | T1(통신사·지상파·전국종합일간) 진입 |

T1 진입은 게임의 규칙이 바뀌는 지점이다. 통신사가 쓰면 전국 매체가 받아쓴다. 한 건이 하루 만에 40건이 된다.

### 축 3. 확산 속도 (0~3)

| 점수 | 조건 |
|---|---|
| 0 | 커뮤니티·SNS 언급 증가 없음 |
| 1 | 전일 대비 2배 미만 |
| 2 | **전일 대비 2배 이상, 또는 단일 게시물 반응 100 이상** |
| 3 | 전일 대비 5배 이상 **그리고** 단일 게시물 반응 500 이상. 또는 실시간 트렌딩 진입 |

축 3은 AND 조건이다. 배수만 크고 절대량이 작으면 3점을 주지 않는다. 어제 1건이 오늘 6건이 되면 6배지만, 6건은 아직 여론이 아니다. 이 규칙이 없으면 매일 3점이 나온다.

### 축 4. 이슈 성격 (0~3)

| 점수 | 조건 |
|---|---|
| 0 | 실적·인사·제품 출시 등 일반 |
| 1 | 서비스 불만, 가격, 약관 |
| 2 | **안전·품질 의혹 제기.** 단, 실제 피해 사례 미확인, 규제기관 미개입 |
| 3 | 실제 피해 발생, 법령 위반, 오너 리스크, 규제기관 조사 착수 |

## 2. 등급 밴드

| 합계 | 등급 | 이름 |
|---|---|---|
| 0 ~ 4 | 1 | 관찰 |
| 5 ~ 8 | 2 | 주의 |
| 9 ~ 11 | 3 | 대응 |
| 12 | 4 | 위기 |

### 즉시 승급 트리거 (점수 무시)

아래 중 하나라도 사실이면 합계 점수와 무관하게 **최소 등급 3(대응)** 으로 올린다.

- T1 매체의 부정 보도 (통신사·지상파·전국종합일간)
- 규제기관의 조사·검토 착수가 보도됨 (공정위, 소비자원, 관계 부처)
- 실제 인적·물적 피해 사례 보도
- 오너·경영진 개인 리스크
- 국회의원 또는 국정감사 지적 (공공 클라이언트의 경우)

점수 체계는 평시의 도구다. 위 다섯 개는 평시가 아니다.

## 3. 등급별 대응 프로토콜

### 등급 1. 관찰

**상황.** 산발적 부정. 확산 없음. 대부분의 날이 여기다.

| 누가 | 언제 | 무엇을 |
|---|---|---|
| 스킬 | 매일 07:00 | 일일 클리핑 리포트 생성 |
| 담당 AE | 출근 후 | 리포트 4분 확인. 이상 없으면 종료 |
| 디렉터 | 주 1회 | 주간 요약만 확인 |

**행동 규칙**
- 보고하지 않는다. 관찰 등급을 매일 보고하면 아무도 안 읽게 된다
- 기록은 남긴다. 3개월 뒤 "이 이슈가 언제부터 있었나"를 물을 때 필요하다
- 약한 신호는 태그만 붙여둔다. 샘플 데이터의 Y-12(댓글 9개짜리 필터 냄새 글)가 그것이다

### 등급 2. 주의 ← 실습 1이 도달하는 지점

**상황.** 동일 이슈로 부정 3건 이상 클러스터. 커뮤니티 확산 시작. 아직 T1 미진입, 규제기관 미개입.

| 누가 | 언제 | 무엇을 |
|---|---|---|
| 스킬 | 감지 즉시 | 이슈 알림 생성 + 홀딩 스테이트먼트 초안 + 예상 Q&A 초안 |
| 담당 AE | **30분 내** | 디렉터 보고. 초안 검토. 사실관계 미확정 항목 표시 |
| 디렉터 | 1시간 내 | 클라이언트 담당자에게 상황 공유. 팩트 확인 요청 |
| 클라이언트 | 당일 | 사실관계 확인. 이것이 병목이고, 이것 없이는 아무것도 못 나간다 |
| 스킬 | 2시간 간격 | 재모니터링. 확산 지수 추적 |

**행동 규칙**
- **홀딩 스테이트먼트는 만들되 배포하지 않는다.** 기자 문의가 오면 쓰기 위해 미리 준비할 뿐이다
- **먼저 나서지 않는다.** 주의 등급에서 자발적으로 보도자료를 내는 것은 대부분 실책이다. 모르던 사람에게 알려주는 꼴이 된다
- **"문제없다"를 확인 없이 쓰지 않는다.** 사실관계가 확정되기 전의 반박은 은폐 프레임의 씨앗이다
- 기자 문의는 담당 AE가 단독 응답하지 않는다. 디렉터와 클라이언트를 거친다
- 이슈 발생 당일에 나가기로 예정된 협찬 콘텐츠, 이벤트, 인플루언서 게시물을 **일시 중단할지 검토한다.** 샘플 데이터의 T-21이 그 사례다

**홀딩 스테이트먼트에 반드시 들어가는 것**
```
1. 해당 사안을 인지하고 있다 (인지 사실)
2. 사실관계를 확인 중이다 (현재 상태)
3. 고객 안전이 최우선이다 (가치 선언)
4. 확인되는 대로 알리겠다 (약속)
```

**절대 들어가면 안 되는 것**
```
× 확인되지 않은 반박 ("문제없다", "사실무근")
× 제보자·소비자단체 비난
× 경쟁사 언급
× 법적 대응 시사
```

### 등급 3. 대응

**상황.** T1 매체 진입, 또는 규제기관 언급, 또는 클러스터 부정 5건 이상.

| 누가 | 언제 | 무엇을 |
|---|---|---|
| 담당 AE | 즉시 | 본부장·클라이언트 동시 보고 |
| 본부장 | 30분 내 | 대응 여부 결정. 대응한다면 채널과 시점 결정 |
| 팀 | 1시간 내 | 공식 입장문 확정 (초안은 스킬이, 확정은 사람이) |
| 팀 | 상시 | 언론 대응 창구 일원화. 응답자 1인 지정 |
| 스킬 | 1시간 간격 | 재모니터링. 확산 지수, T1 매체 추가 진입 감시 |

**행동 규칙**
- 대응 여부를 결정하는 사람의 직급이 올라간다. AE가 결정하지 않는다
- 창구를 하나로 좁힌다. 여러 사람이 다른 말을 하면 그 자체가 기사가 된다
- 입장문에 담을 사실은 **전부 클라이언트가 서면으로 확인한 것만** 쓴다
- 후속 조치(교체, 환불, 재시험)를 함께 발표할 수 있는지 검토한다. 사과만 있고 조치가 없으면 두 번 사과하게 된다

### 등급 4. 위기

**상황.** 실제 피해, 지상파 메인뉴스, 규제기관 조사 착수, 전국 확산.

| 누가 | 언제 | 무엇을 |
|---|---|---|
| 본부장 | 즉시 | 위기관리위원회 소집 |
| 위기관리위원회 | 소집 즉시 | 대응 전략 결정. 경영진·법무 참여 |
| 팀 | 상시 | 시간 단위 모니터링. 상황판 운영 |
| 스킬 | 30분 간격 | 수집만. 판단 산출물은 내지 않는다 |

**행동 규칙**
- **이 단계에서 스킬의 역할은 축소된다.** 자동 생성 문안을 쓰지 않는다. 수집과 정리만 한다
- 위기 대응은 커뮤니케이션 문제가 아니라 경영 문제다. PR팀이 단독으로 풀 수 없다
- 모든 발언은 법무 검토를 거친다
- 상황이 종료된 뒤 **왜 등급 2에서 잡지 못했는지** 복기한다. 위기의 대부분은 주의 단계에서 이미 보였다

## 4. 오탐과 미탐

경보 체계를 만들면 반드시 이 질문이 온다. **기준선을 어디에 둘 것인가.**

```
기준선을 낮추면  →  오탐 증가  →  경보 피로  →  아무도 안 본다  →  진짜 위기를 놓친다
기준선을 높이면  →  미탐 증가  →  못 잡는다   →  주의 단계를 건너뛰고 위기로 간다
```

둘 다 결과는 같다. **놓친다.** 그래서 "정확한 기준선"을 찾으려 하지 말고, 다음 세 가지로 관리한다.

### 관리법 1. 등급마다 비용을 다르게 설계한다

관찰 등급은 아무도 부르지 않는다. 그래서 오탐이 나도 비용이 0이다. 반대로 위기 등급은 위원회를 소집한다. 그래서 즉시 승급 트리거를 엄격하게 잡았다.

**오탐 비용이 낮은 등급에서는 관대하게, 높은 등급에서는 엄격하게.** 이것이 기준선 하나로 해결하려는 시도보다 낫다.

### 관리법 2. 경보를 매일 보내지 않는다

관찰 등급에서는 알림이 가지 않는다. 리포트만 저장된다. 알림이 온다는 것 자체가 신호가 되어야 한다. **한 달에 두세 번 오는 알림은 읽히고, 매일 오는 알림은 읽히지 않는다.**

### 관리법 3. 기준선을 팀 실정에 맞춰 조정한다

| 클라이언트 유형 | 기준선 | 이유 |
|---|---|---|
| 소비재 브랜드 | 표준 | 오탐 비용과 미탐 비용이 비슷하다 |
| 공공기관·정책 | **낮게** | 미탐 비용이 압도적으로 크다. 국정감사 시즌에는 관찰 등급도 보고한다 |
| 상장 대기업 | **낮게** | 주가에 즉시 반영된다. 시간이 곧 돈이다 |
| B2B·산업재 | 높게 | 일반 여론의 영향이 작다. 오탐이 더 비싸다 |

## 5. 공공 클라이언트의 변형 프로토콜

정책 이슈는 확산 경로가 다르다. 프로토콜도 달라야 한다.

### 시차를 이용한다

```
기업 이슈  :  언론 보도  →  커뮤니티 반응  →  확산
              (감지 시점이 이미 공개된 뒤다)

공공 이슈  :  커뮤니티·댓글 과열  →  [2~5일]  →  언론이 "논란"으로 받음
              (감지 시점이 보도 전이다. 이 며칠이 대응 시간이다)
```

**공공 클라이언트는 언론이 아니라 댓글이 1차 감지 채널이다.** 축 3(확산 속도)의 가중치를 올리고, 축 2(매체 등급)의 가중치를 내린다.

### 추가 감지 신호

| 신호 | 의미 |
|---|---|
| **댓글 논조 역전** | 기사 본문은 중립인데 상위 댓글 10개가 부정. 가장 강한 조기 신호다 |
| 국민청원·민원 급증 | 제도권 진입 직전 |
| 국회의원 SNS 언급 | 국정감사 지적으로 이어질 확률이 높다 |
| 야당 논평 | 정치 이슈화 시작. 이 시점부터는 커뮤니케이션으로 못 막는다 |

### 공공에서 특히 조심할 것

- **정책 자체를 방어하지 않는다.** PR이 할 수 있는 것은 사실관계 정정과 소통 방식 개선이지 정책의 정당성 변호가 아니다. 선을 넘으면 대행사가 정치적 공격의 대상이 된다
- **부처 승인 없는 어떤 문안도 나가지 않는다.** 기업보다 승인 라인이 길다. 초안 준비 시간을 앞당기는 것으로 대응 속도를 확보한다
- **여론을 조작하는 어떤 행위도 하지 않는다.** 댓글 대응, 커뮤니티 여론 조성은 프로토콜 밖이다. 이것은 속도의 문제가 아니라 선의 문제다

## 6. 등급 판정 검증 체크리스트

스킬이 등급을 내면 사람이 이 5개를 확인한다. 5개 다 통과해야 등급이 확정된다.

- [ ] 클러스터에 묶인 기사가 정말 같은 이슈인가. 경쟁사 기사가 섞이지 않았나 (샘플 T-09)
- [ ] 논조 판정이 신뢰도 0.7 미만인 건을 사람이 다시 읽었나 (샘플 T-10)
- [ ] 확산 지수의 절대량을 확인했나. 배수만 크고 건수가 작지 않은가
- [ ] 즉시 승급 트리거 5개를 하나씩 확인했나
- [ ] 이 등급으로 움직였을 때, 움직이지 않았을 때보다 나은가. **대응하지 않는 것도 선택지다**
