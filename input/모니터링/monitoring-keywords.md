# 모니터링 키워드 세트 (샘플)

> **전부 가상이다.** 브랜드, 인물, 제품, 매체, 이슈 모두 실습용으로 만든 것이며 실재하는 기업·매체·사건과 무관하다.
> 실습 1은 이 세트를 그대로 쓴다. 실습 2에서 본인 담당 클라이언트로 교체한다.

## 클라이언트 개요

| 항목 | 내용 |
|---|---|
| 클라이언트 | 누리솔전자 (가상) |
| 업종 | 생활가전. 공기청정기·정수기 제조 및 렌탈 |
| 담당 AE | 소비재 2팀 |
| 계약 범위 | 언론 홍보, 온라인 이슈 모니터링, 위기 대응 자문 |
| 모니터링 주기 | 매일 오전 7시 자동 수집. 주의 등급 이상 시 즉시 |

## 왜 키워드 세트를 먼저 만드는가

모니터링은 검색어를 정하는 순간 결과가 결정된다. 브랜드명만 넣으면 브랜드명이 안 나오는 기사를 놓친다. **위기는 브랜드명이 제목에 없는 기사에서 시작하는 경우가 많다.** "공기청정기 필터 유해물질 검출"이라는 제목의 기사에 우리 브랜드는 본문 다섯 번째 문단에 있다.

그래서 5개 층으로 나눠서 잡는다.

## 1층. 브랜드·법인명

가장 기본. 표기 흔들림을 모두 넣는다.

```
누리솔
누리솔전자
누리솔 전자
NURISOL
(주)누리솔전자
누리솔전자㈜
```

주의할 점: 띄어쓰기와 영문 표기를 빠뜨리면 검색 결과가 통째로 빠진다. 특히 온라인 커뮤니티는 표기가 자유롭다.

## 2층. 인물명

대표자, 임원, 홍보 담당자. 오너 리스크는 브랜드명이 아니라 사람 이름으로 온다.

```
정한섭 (대표이사)
정한섭 대표
누리솔 대표
윤미래 (마케팅본부장)
누리솔 오너
```

인물 키워드는 **동명이인 노이즈**가 많다. 반드시 브랜드명과 함께 걸리는지 확인하는 2차 필터를 둔다.

## 3층. 제품·서비스명

```
에어퓨어 (공기청정기 라인)
에어퓨어 X3
에어퓨어 X1
워터핏 (정수기 라인)
워터핏 미니
누리솔 렌탈
누리솔 케어서비스
```

제품명 단독 검색이 중요하다. 커뮤니티에서는 브랜드명 없이 "에어퓨어 필터"만 언급된다.

## 4층. 업계 이슈어

우리 이름이 안 나와도, 우리가 휘말릴 수 있는 주제어다. **이 층이 조기 경보의 핵심이다.**

```
공기청정기 필터
공기청정기 유해물질
필터 인증
CA 인증
KC 인증
정수기 위생
렌탈 위약금
렌탈 해지
생활가전 리콜
가전 안전기준
실내공기질
```

이 키워드들은 브랜드명 없이도 수집한다. 수집 후 본문에 브랜드 언급이 있으면 "간접 노출"로, 없으면 "업계 배경"으로 분류한다. 업계 배경도 버리지 않는다. 경쟁사에서 터진 이슈가 3일 뒤 업계 전체 이슈가 되어 우리에게 오는 일이 흔하다.

## 5층. 위험 신호어

이 단어가 브랜드명과 같은 문서에 등장하면 **자동으로 논조 재검토 대상**이 된다. 그리고 위험도 판정 축 4(이슈 성격)의 입력이 된다.

### 5-A. 안전·품질

```
유해물질 · 기준치 초과 · 검출 · 발암 · 인체 유해
결함 · 하자 · 화재 · 감전 · 폭발 · 오작동
리콜 · 무상교체 · 전수조사 · 수거
```

### 5-B. 규제·법률

```
공정거래위원회 · 공정위 · 소비자원 · 한국소비자원
과징금 · 시정명령 · 제재 · 조사 착수 · 압수수색
집단분쟁조정 · 소송 · 고발 · 피소 · 손해배상
표시광고법 · 제조물책임 · 전기용품안전관리법
```

### 5-C. 여론·평판

```
논란 · 의혹 · 파문 · 뭇매 · 도마
불매 · 보이콧 · 실망 · 배신
갑질 · 은폐 · 축소 · 늑장 · 무책임
해명 · 사과 · 입장문 · 공식 입장
```

### 5-D. 확산 신호

```
단독 · 취재 결과 · 확인됐다
맘카페 · 커뮤니티 확산 · 청원 · 국민청원
실시간 검색 · 트렌딩 · 화제
```

## 제외 키워드 (노이즈 필터)

수집은 하되 클리핑에서 빼는 것들. 안 걸러내면 리포트가 광고로 뒤덮인다.

```
쿠팡 · 11번가 · G마켓 · 최저가 · 특가 · 할인코드
제휴 · 광고 · 협찬 표기 없는 판매 링크
채용공고 (별도 트랙으로 분리)
주식 종목토론방 (별도 트랙으로 분리)
```

제외 키워드는 **삭제가 아니라 분리**다. 나중에 "왜 그때 이걸 못 봤나"라는 질문이 나오면 원천 데이터로 돌아가야 한다.

## 부록. 공공 클라이언트 키워드 세트는 다르다

같은 5층 구조를 쓰지만 무게중심이 바뀐다. 가상의 공공 캠페인을 예로 든다.

**클라이언트: 국가디지털배움터 사업 (가상, 정부 부처 캠페인)**

| 층 | 기업 클라이언트 | 공공 클라이언트 |
|---|---|---|
| 1층 브랜드 | 브랜드명·법인명 | 사업명 + 주관 부처명 + 예산 항목명 |
| 2층 인물 | 대표·임원 | 장관·차관·국장 + **국회의원** (국정감사 지적) |
| 3층 제품 | 제품 라인 | 세부 프로그램명, 지역별 운영기관명 |
| 4층 업계 이슈어 | 업계 안전·규제 | **정책 논쟁 프레임어** (예산 낭비, 실효성 없음, 전시행정, 중복 사업) |
| 5층 위험 신호어 | 리콜·과징금 | **국정감사, 감사원, 예산 삭감, 국민청원, 지적, 실적 부풀리기** |

가장 큰 차이는 **감지 채널의 순서**다.

```
기업 이슈  :  언론 보도  →  커뮤니티 반응  →  확산
공공 이슈  :  커뮤니티·댓글  →  (며칠)  →  언론이 "논란" 제목으로 받음
```

공공 클라이언트는 **댓글과 커뮤니티를 언론보다 앞선 신호로 취급한다.** 기사 댓글 상위 10개의 논조가 기사 본문 논조와 반대로 뒤집히는 순간이 가장 중요한 신호다. 그래서 공공 세트는 5층에 `댓글 논조 역전` 항목을 추가로 둔다.
