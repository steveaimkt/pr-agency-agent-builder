# 무엇부터 자동화할까 · 트랙 고르기

> 아홉 트랙 중 무엇으로 시작할지 정하는 문서다. 강사와 수강생이 같이 본다.
> 처음이라 막막하면 SKILL.md 의 ① 업무 진단 문답을 먼저 돌린다.

## 고르는 기준은 둘뿐이다

```
빈도 × 소요시간          매일 30분이 매달 3시간보다 크다
판단이 몇 번 들어가나     순서 고정이면 스킬, 판단이 여러 번이면 에이전트
```

⛔ **"제일 어려운 일"을 고르지 않는다.** 제일 자주 오는 일을 고른다.
어려운 일은 자주 오지 않고, 자주 오지 않는 일은 만들어도 다시 안 부른다.

## 아홉 트랙 · 대행사에서 자주 나오는 순서

| # | 업무 | 갈래 | 권장 그릇 | 권장 산출물 |
|---|---|---|---|---|
| 01 | 제안서·기획서 구조화·PPT 제작 | 기획 | 에이전트 | 파워포인트 |
| 02 | 타깃 인사이트·캠페인 콘셉트 기획 | 기획 | 에이전트 | 파워포인트 |
| 03 | 고객사 보고서 작성 (월간·주간) | 문서 | 에이전트 | 파워포인트 |
| 04 | 시장·경쟁사 리서치 | 리서치 | 에이전트 | 워드 |
| 05 | SNS 콘텐츠 기획·카피라이팅 | 콘텐츠 | 에이전트 | 엑셀 |
| 06 | 이미지·영상 생성 | 콘텐츠 | 스킬 | 웹 화면 |
| 07 | 보도자료 초안·메시지 정리 | 문서 | 에이전트 | 워드 |
| 08 | 클리핑·미디어 모니터링 | 모니터링 | 에이전트 | 웹 화면 |
| 09 | 회의록 정리·문서 초안 작성 | 문서 | 스킬 | 워드 |

⭐ **상위 넷(01~04)이 가장 자주 나온다.** 시간이 밀리면 이 넷 안에서 고르게 한다.

## 처음이면 06 이나 09 로 시작해도 된다

둘은 그릇이 **스킬**이다. 순서가 고정이라 만들기 쉽고, 한 시간 안에 끝이 보인다.
성공 경험을 먼저 만들고 01 같은 큰 것으로 넘어가는 편이 낫다.

## 시간이 밀릴 때 자르는 순서

```
1  ⑧ 강화 검토를 뺀다            선택 단계다
2  ⑤ 검증 8항목을 넷으로 줄인다    병목 · 자료 · 게이트 · 룰
3  ④ 스텝을 5개로 고정한다        7개까지 늘리지 않는다
```

⛔ **자르지 않는 둘**

```
③ 자료와 잘된 결과물 모으기      이걸 빼면 남의 형식이 나온다
⑥ 돌려 보고 한 번 고치기         이걸 빼면 초안으로 끝난다
```

## 강사 메모

- 숙련층이 생각보다 두껍다. **기초 설명을 길게 하면 지루해한다.** 개념은 두 줄에서 네 줄로 끊는다.
- 반대로 클로드 계정이 없는 분이 섞여 있다. **시작 전에 로그인부터 확인하는 자리**를 둔다.
- 화면 안내는 윈도우 기준으로 하고, 맥은 단축키만 따로 적는다.
- 자주 나오는 요청 · 반복 업무 자동화 · 나만의 에이전트와 스킬 구축 · 검수를 덜 하고 싶다 ·
  국내 독자에게 안 어색한 문장. 넷 다 ③ 자료 모으기와 ⑥ 고치기에서 풀린다.
