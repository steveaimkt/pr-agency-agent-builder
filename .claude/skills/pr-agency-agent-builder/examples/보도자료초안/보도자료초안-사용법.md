# 보도자료 초안 에이전트 · 사용법

> 여섯 줄만 알면 쓴다.

**1. 부르는 법**
채팅창에 한 줄. `보도자료 초안 만들자`
스킬 폴더는 `.claude/skills/press-release-draft/` 에 둔다. 폴더명이 곧 트리거다.

**2. 넣을 것**
팩트시트 한 장. 없으면 `input/콘텐츠/fact-sheet.md` 로 시작한다.
같이 읽는 기준 파일 둘 · `input/콘텐츠/media-list.md` (매체 앵글) ·
`input/콘텐츠/brand-voice.md` (금기 표현 표).
고객사명·담당자는 A사로 가린 상태로 넣는다.

**3. 멈추는 곳**
스텝마다 묻고 멈춘다. 진짜 게이트는 **STEP 5 배포 전 확인**이다.
팩트 대조 결과, `[FACT-CHECK]` 항목, 금기 표현 검출 목록 셋을 보고 통과시켜야 저장으로 넘어간다.
인용문에 규제에 걸리는 표현이 있으면 에이전트가 고치지 않고 사람에게 넘긴다.

**4. 나오는 것**
`output/보도자료-{고객사}-{YYYY-MM-DD}.md`
제목 · 부제 · 리드 · 본문 · 인용 · 부가 정보 · 팩트박스 · 회사 소개 · 문의처.
팩트시트에 없는 값은 `[FACT-CHECK]` 로 비어 있다. 그 자리는 사람이 채운다.

**5. 어디서**
만드는 곳과 돌리는 곳이 다르다.
🏗️ 제작·수정 = 이 스킬 폴더에서 · ▶️ 실행 = 클로드 코드 채팅창에서 트리거 한 줄로.
견본 한 벌은 `examples/보도자료초안/` 에 있다. 워크시트 → 스킬 → 산출물 순서로 보면 된다.

**6. 고치려면**
- 리드 각도나 분량이 안 맞으면 → SKILL.md 의 STEP 2·STEP 3
- 못 잡는 표현이 있으면 → `brand-voice.md` 금기 표현 표에 한 줄 추가 (표에 없으면 검출되지 않는다)
- 단계가 빠지거나 순서가 틀리면 → 워크시트 F칸을 고치고 SKILL.md 의 STEP을 맞춘다
- 클라이언트 업종이 바뀌면 → `brand-voice.md` 업종 프리셋 행으로 표 3장을 통째로 갈아 끼운다
