# outputs · 여기가 아니라 루트 `output/` 에 쌓인다

⛔ **이 폴더에는 산출물을 남기지 않는다.** 도구도 안내문도 전부 루트 `output/` 을 쓴다.
자리가 둘이면 만든 파일을 다시 못 찾는다. **자리는 루트 `output/` 하나다.**

스킬을 끝까지 돌리면 루트 `output/` 에 인도 3종이 떨어진다.
1. `output/<업무명>-SKILL.md` · 트리거로 다시 부르는 에이전트 본체
2. `output/<업무명>-결과-<날짜>.*` · 실제로 나온 산출물 파일
3. `output/<업무명>-사용법.md` · 부르는 법 · 멈추는 곳 · 고치는 법

워크시트는 산출물이 아니라 작업 파일이다. **스킬 폴더 안** `../specs/<업무명>-워크시트.md` 에 둔다.
