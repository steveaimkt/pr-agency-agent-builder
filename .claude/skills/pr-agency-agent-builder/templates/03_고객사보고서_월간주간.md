# 트랙 03 · 고객사 보고서 작성 (월간·주간)

> 대행사에서 자주 나오는 업무 · "고객사 보고서 작성 (월간·주간)" (많이 고르는 순서 3위)
> 갈래 · 문서 · 권장 그릇 · **스킬**

## 병목 · 어디서 시간이 가나
- 클리핑, SNS 숫자, 광고 숫자가 각각 다른 파일에 있어서 한 장으로 모으는 데 시간이 간다.
- 매주·매달 같은 양식을 손으로 다시 만든다. 표를 지우고 새로 채우는 반복 작업이다.
- 전월 대비 증감을 사람이 눈으로 계산하다 숫자를 잘못 옮기는 실수가 난다.
- 여러 고객사를 동시에 담당할 때, 고객사마다 보고서 양식이 조금씩 달라서 매번 표를 다시 짠다.
- 주간 보고서는 발송 주기가 짧아, 자료가 다 모이기 전에 급하게 먼저 만들다 숫자가 어긋난다.

## 입력 / 출력
- **입력** · 클리핑 목록, SNS 지표, 광고 집행 요약, KPI 목표
- **출력** · 월간·주간 보고서 1장, 지표 표, 전월 대비 증감 표시, 다음 주 액션
- 지표 표는 이번 달 값, 전월 값, 증감률, 목표 대비 달성률 넷을 한 줄에 놓는다.
- 광고환산가치는 매체 등급, 노출량, 단가를 곱해 계산하고 산정식을 각주로 남긴다.

## 판단 룰 (숫자로 못박는다)
- 노출·도달·광고환산가치가 전월 대비 ±20%를 넘으면 원인 문단을 반드시 붙인다.
- KPI 목표 대비 달성률이 80% 미만인 지표는 빨간 표시를 한다.
- 클리핑 기사는 제목·매체·날짜·링크·세 줄 요약까지만 옮긴다. 전문은 옮기지 않는다.
- 부정 기사가 지난달보다 2건 넘게 늘면 위기관리 담당에게 바로 알린다.
- 다음 주 액션 항목은 3개를 넘지 않는다. 많으면 우선순위가 안 보인다.

## 스텝 초안 (5~7)
| 스텝 | 입력 → 처리 → 출력 | 담당 |
|---|---|---|
| 1 | 클리핑 목록(csv) → 매체·건수를 센다 → 클리핑 요약표 | AI |
| 2 | SNS 지표(json) → 채널별로 정리한다 → SNS 요약표 | AI |
| 3 | 광고 집행 요약(csv) → 노출·도달·광고환산가치를 계산한다 → 광고 요약표 | AI |
| 4 | 세 요약표 + KPI 목표 → 전월 대비 증감을 붙인다 → 증감 표시 보고서 | AI |
| 5 | 증감 표시 보고서 → 원인 문단·다음 주 액션을 채운다 → 보고서 초안 | AI |
| 6 | 보고서 초안 → 사람이 확인·보완 → 확정 보고서 | 사람 |
| 7 | 확정 보고서 → 고객사 양식에 맞춰 낸다 → 최종 보고서 파일 | AI |

## 사람 개입 게이트
- 고객사 발송 전. 증감 원인 문단과 숫자가 원자료와 맞는지 확인한 사람이 서명한다.
- 광고환산가치처럼 산정 기준이 있는 숫자는 산정 방식을 함께 적어 오해를 막는다.
- 부정 기사가 늘어 위기관리 담당에게 알린 뒤에는, 보고서 발송 전에 대응 상황을 한 줄 더 확인한다.
- 고객사마다 다른 보고서 양식은 첫 회차에 확인해 두고, 다음부터는 같은 양식으로 낸다.

## 도구
- **읽기** · csv·json 읽기 스킬로 클리핑·SNS·광고 원자료를 연다
- **만들기** · 중간 산출물은 `.md` 로 만든다. 고치기 쉽고 다시 돌리기 쉽다
- **내보내기** · 마지막에 형식을 고른다. 이 트랙에 맞는 것은 **파워포인트** 이다. 숫자 원장은 엑셀로 함께 낸다
  | 고르면 | 무엇으로 | 언제 |
  |---|---|---|
  | 파워포인트 | 공식 스킬 `pptx` | 발표하거나 고객사에 보고할 때 |
  | 워드 | 공식 스킬 `docx` | 문서로 넘기고 상대가 고쳐 써야 할 때 |
  | 엑셀 | 공식 스킬 `xlsx` | 표와 숫자가 본체일 때 |
  | 웹 화면 | `tools/md2html.py` | 빨리 보고 링크로 돌려볼 때 |
- **디자인** · 색과 글꼴을 새로 고르지 않는다. `design-system/colors_and_type.css` 를 물리고,
  장표는 `tools/slide-design.md`, 문서는 `tools/design.md` 규격 그대로 간다. 형광은 한 장에 한 번만
- **검산** · 전월 값과 이번 달 값을 나란히 놓고 증감률 계산을 다시 맞춰 본다. 부정 기사 급증처럼 급한 신호는 보고서보다 먼저 담당자에게 짧게 알린다

## 샘플 자료 · 내 파일이 없으면 이걸로 시작한다
- `input/문서/clipping-2026-06.csv` · 클리핑 원자료 견본. 클리핑 요약표의 입력
- `input/문서/sns-metrics.json` · SNS 지표 원자료. SNS 요약표의 입력
- `input/문서/ads-summary.csv` · 광고 집행 요약. 광고 요약표의 입력
- `input/문서/kpi-targets.md` · KPI 목표. 증감 표시와 달성률 계산의 기준
- `input/문서/doc-templates.md` · 보고서 양식 견본. 최종 출력의 정답 견본
- `input/모니터링/today-coverage.json` · 오늘 보도 스냅샷. 주간 보고서 실습용
- `input/모니터링/yesterday-snapshot.json` · 어제 스냅샷. 하루 단위 증감 연습용
- `input/내자료/매체단가표.md` · 매체 등급별 단가. 광고환산가치 계산의 기준
- `input/교체용/clipping-2026-07.csv` · 2회차 실습용 교체 클리핑
- `input/교체용/today-snapshot.json` · 2회차 실습용 교체 오늘 스냅샷

## 자주 나오는 함정
- 광고환산가치를 매체 등급 구분 없이 하나의 단가로 계산하는 실수. 매체단가표를 반드시 확인한다.
- 전월 자료가 없을 때 증감을 0으로 채우는 것. 자료가 없으면 "비교 불가"로 남기고 지어내지 않는다.
- 부정 기사 건수만 세고 내용은 안 읽는 것. 위기관리로 연결할지는 내용을 읽어야 판단할 수 있다.
