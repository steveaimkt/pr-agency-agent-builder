# PR 대행사 업무 에이전트 빌더

> 내 반복업무 하나를 **트리거 한 줄로 부르는 에이전트**로 만드는 게이트형 클로드 코드 스킬.
> 코딩을 몰라도 된다. 무엇을·왜·어떤 기준으로 할지만 답하면 코드는 AI가 쓴다.

PR·홍보 대행사 실무자를 위한 교육·실습용 공개본이다. 고객사 정보는 모두 익명 처리했다.

## 무엇을 하나

```
[① 만들기]   업무를 말로 답하면 그 답이 모여 SKILL.md 한 장(= 에이전트)이 만들어진다
[② 부르기]   "보도자료 초안 만들자" 한 줄이면 스스로 돌며 입력을 요청하고, 게이트에서 멈춰 확인받는다
[③ 남는 것]  ① 트리거로 부르는 에이전트 ② 실제 산출물 파일 ③ 사용법 카드
```

아홉 개 밖의 업무도 워크시트 여덟 칸만 새로 채우면 같은 방식으로 만들어진다.

## 폴더

```
.claude/skills/pr-agency-agent-builder/
  SKILL.md                     게이트 흐름 0단계 → PHASE 0 → ①~⑧
  templates/00_업무구체화_워크시트.md   설계서 여덟 칸 A~H
  templates/01~09              아홉 트랙
  references/00_방법론.md        에이전트란 무엇이고 어떻게 만드나
  references/01_완성예시.md       보도자료 에이전트 한 벌 (SKILL.md 전문 포함)
  references/02_트랙_고르기.md     무엇부터 자동화할지 정하는 법
  examples/보도자료초안/          채운 워크시트 · 스킬 · 산출물 · 사용법
  specs/                       작업 공간
  outputs/                     인도 3종이 떨어지는 곳
input/                         샘플 자료 (가상 브랜드·가상 기관)
tools/md2html.py               웹 화면으로 빨리 보기
output/                        산출물이 쌓이는 곳
```

## 쓰는 법

1. 이 폴더를 내려받아 클로드 코드로 연다.
2. 입력창에 `에이전트 구축하자` 라고 친다.
3. 한 단계씩 물어보면 답한다. 답을 안 하면 다음으로 가지 않는다.

## 산출물 형식은 마지막에 고른다

내용이 확정되기 전에는 `.md` 로 만든다. 고치기 쉽고 다시 돌리기 쉽기 때문이다.
마지막에 넷 중 하나를 고른다.

| 고르면 | 무엇으로 | 언제 |
|---|---|---|
| 파워포인트 (.pptx) | 공식 스킬 `pptx` | 발표하거나 고객사에 보고할 때 |
| 워드 (.docx) | 공식 스킬 `docx` | 문서로 넘기고 상대가 고쳐 써야 할 때 |
| 엑셀 (.xlsx) | 공식 스킬 `xlsx` | 표와 숫자가 본체일 때 |
| 웹 화면 (.html) | `tools/md2html.py` | 빨리 보고 링크로 돌려볼 때 |

### 공식 스킬 붙이기

파워포인트·워드·엑셀은 앤트로픽이 공개한 스킬을 그대로 쓴다.
라이선스 때문에 이 저장소에 함께 넣지 않았다. 아래에서 받아 `.claude/skills/` 에 넣으면 된다.

```
https://github.com/anthropics/skills
```

받을 것은 `document-skills/` 아래의 `docx` · `pptx` · `xlsx` · `pdf` 넷이다.
넣은 뒤 클로드 코드를 껐다 켜면 이름만 불러도 붙는다.

## 비협상 안전 규칙 다섯

1. **읽기 우선** · 보내고 올리고 지우는 손은 기본으로 잠근다. 원본 자료는 고치지 않는다.
2. **마스킹** · 고객사명·담당자·단가·미공개 일정은 넣기 전에 A사·B사로 가린다.
3. **사람 확정** · 배포·제출·외부 공개·언론 응대는 사람이 확인한 뒤에 나간다.
4. **사실 확인** · 숫자·인용·수상 이력·기관명은 자료에 없으면 지어내지 않는다. `[FACT-CHECK]` 만 남긴다.
5. **저작권** · 기사 전문을 옮기지 않는다. 제목·매체·날짜·링크·세 줄 요약까지만.
   생성한 이미지와 영상은 상업 사용 조건을 확인하기 전에는 고객사에 넘기지 않는다.
