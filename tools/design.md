# 디자인 · 색은 컨셉에서, 규칙은 여기서

> ⭐ **색과 글꼴은 `config.md` 의 「디자인 컨셉」에서 가져온다.**
> 아래 값은 **컨셉을 「차분한 뉴트럴」로 정했을 때의 보기**다.
> 컨셉이 다르면 그 값으로 바꿔 넣고, **아래 규칙은 그대로 지킨다.**
> ⛔ **담당자가 색을 스스로 고르지 않는다.** 안 정해졌으면 사람에게 묻는다.

---

## 색 · 여섯 개면 충분하다

```
잉크      #2A2A28     글자 · 어두운 배경 · 강조     ← 순검정이 아니라 따뜻한 근검정
종이      #F3F3F2     바탕
카드      #FFFFFF     표와 상자
헤어라인   #EBEBEB     선. 굵기는 1px 하나뿐
샌드      #E0CCBE     따뜻한 강조. 아주 가끔
형광      #EBFF2C     확인 필요 표시. 한 장에 한 번
```

**보조 글자색**

```
#444444   본문
#4C4D59   보조 설명
#848383   메타 · 캡션
#AFAFAC   흐린 것
```

**판정 색 셋** · 달성률에만 쓴다. 이 셋 말고 다른 데 쓰지 않는다

```
#3F7D54   100% 넘음
#8A6F2C   90 ~ 100%
#A8452F   90% 못 미침
```

⛔ **남색 · 파랑을 쓰지 않는다.** 이 브랜드에 없는 색이다.
⛔ **초록은 달성률 판정에만 쓴다.** 제목이나 배경에 쓰지 않는다.
⛔ **그라디언트를 쓰지 않는다.** 배경은 단색이다.

⭐ **`tools/md2html.py` 가 이 값을 다 갖고 있다.** 직접 CSS 를 쓰지 않는다.

## 글자

```
글꼴     Pretendard  →  Apple SD Gothic Neo  →  Noto Sans KR  순으로 잡는다
본문     16px / 줄간격 1.7

표       15px

```

⚠️ **어절 중간에서 줄을 끊지 않는다.** `word-break: keep-all` 을 넣는다.

```

## 문서를 만들 때

**`tools/md2html.py` 가 이 값을 이미 갖고 있다.** 직접 CSS 를 쓰지 말고 이걸 쓴다.

```
python3 tools/md2html.py output/03-월간보고서.md
```

**스타일이 파일 안에 다 들어간다.** 메일로 보내도 안 깨지고, 인쇄하면 PDF 가 된다.

---

## 슬라이드를 만들 때

**HTML 슬라이드**

⭐ **장표는 `tools/slide-design.md` 를 연다.** 복사해서 쓸 조각이 다 들어 있다.
판 크기 · 글꼴 · 표 · 막대 · 확인 필요 표시가 값까지 적혀 있다.

```
1280 × 720 고정 · 패딩 64px 72px
표와 막대는 흰 카드(모서리 24px) 안에 넣는다
제목은 이름표가 아니라 결론 한 줄
모든 장에 머리 표시와 바닥 두 줄
```

**PPT 파일**

```
node tools/pptx/make-deck.js output/02-제안-목차.md output/03-챕터-초안.md
```

⚠️ `node` 가 있어야 한다. 없으면 HTML 로 간다. **HTML 이 못한 게 아니다.**

## 도식 · 셋뿐이다

**표와 문단만 있으면 안 읽힌다.** 아래 셋을 쓴다. `md2html.py` 가 그림으로 바꿔 준다.

**① 숫자 카드** · 문서 맨 앞에 둔다. 제일 먼저 눈에 들어온다

```
```숫자 6월 한눈에
40건 총 노출 · 좋음
50% 핵심 메시지 반영률 · 나쁨
99건 분기 누적 · 좋음
```
```

**② 막대** · 서로 견주는 값이 셋 이상일 때

```
```막대 논조 분포
긍정 24
중립 13
부정 3
```
```

**③ 달성률** · 목표 대비일 때. **100% 넘으면 초록, 90% 못 미치면 빨강**

```
```달성 목표 대비
월간 노출 133
핵심 메시지 반영 50
```
```

⛔ **단위가 다른 걸 한 막대에 섞지 않는다.** 42,000명과 30건을 나란히 놓으면 뜻이 없다.
⛔ **합계는 넣지 않는다.** 다른 막대를 눌러 버린다.
⚠️ **아무 표에나 붙이지 않는다.** 그릴 값이 있을 때만 그린다. **틀린 그래프는 없는 것보다 나쁘다.**

⭐ **최소한 문서 맨 앞에 「숫자 카드」 하나는 넣는다.**

---

## 확인 필요 표시

```
[FACT-CHECK]     형광 #EBFF2C 배경 · 잉크 글자 · 굵게
```

⛔ **노란 게 하나라도 남아 있으면 밖으로 나가는 문서가 아니다.**
표시는 **자료를 못 받아 비운 자리**라는 뜻이다. 지우지 말고 채우거나, 채울 자료를 요청한다.

---

## 왜 이렇게 정해 두나

색을 매번 고르면 **같은 회사가 만든 것으로 안 보인다.**
그리고 고르는 데 시간이 든다. **여섯 색이면 충분하다.**

오늘 보는 강의 화면도 이 값으로 만들었다. **손에 남는 문서와 같은 옷이다.**
